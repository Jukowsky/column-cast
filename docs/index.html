redcast

An audio archive of opinion columns.

redcast is a personal automation tool that follows the opinion columns published on haber.sol.org.tr each day, narrates them with a Turkish synthetic (text-to-speech) voice, and publishes the recordings on a YouTube channel. Its purpose is to offer a listenable alternative for people who don't have time to read the columns and for screen-reader users.

How it works

  1. The columns page is checked once a day, and columns not yet processed are collected.
  2. The column text is narrated with a Turkish text-to-speech engine.
  3. The audio is turned into a video with a static card showing the column's title and author.
  4. The video is uploaded to the account owner's own channel using the YouTube Data API v3.

Source and rights

All rights to the columns belong to their authors. redcast only provides narration; it does not alter, shorten or comment on the texts. Each recording's description includes the author's name, the publication date, a note that the recording was produced with a synthetic voice, and a link to the original column. Recordings are taken down at the request of the rights holders.
