Privacy Policy

redcast — last updated: August 29, 2026

redcast is a personal automation tool used by a single person to publish to their own YouTube channel. It does not offer a service to anyone else, does not create user accounts, and does not collect data from visitors.

Data collected

redcast does not collect data from any third party. The only account the application accesses is the Google account of the person who runs it, and that access is granted only with that person's explicit consent (through the Google OAuth consent screen).

Use of Google user data

The application requests the following YouTube Data API v3 permissions:

  • youtube.upload — to upload the narrated recordings to the account owner's own channel.
  • youtube.readonly — only to verify the name of the connected channel, i.e. to confirm that uploads go to the correct channel.

These permissions are not used for any other purpose. The application does not watch or delete videos, does not read or write comments, and does not access viewer data.

Storage and security

  • The authorization token issued by Google (OAuth refresh token) is stored only on the server where the application runs, in a single file protected by file-system permissions.
  • The token is never passed to any third party or sent to any external service.
  • The only other record the application keeps is a list of which columns have been processed, made up of publicly available information (column URL, title, author, date). This list contains no personal data.
  • Authorization can be revoked at any time from the Google Account permissions page; the application's access ends immediately when it is.

Data sharing

No data is sold, rented or shared with third parties. The application's only exchange with the outside world is the requests it makes to Google's YouTube API to upload recordings to the account owner's own channel.

redcast's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Published content

The narrated texts are opinion columns that have been publicly published. Their rights belong to their authors and the publisher; each recording's description credits the source and links to the original column. Takedown requests can be sent to the address below.
